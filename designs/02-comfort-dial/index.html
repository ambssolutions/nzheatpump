How an install goes

  1. 01

    Site visit

    We measure up and talk through where the indoor and outdoor units will go. You see the options before anything is decided.

  2. 02

    Written quote

    The unit, the install and any electrical work, named on one quote. If the switchboard needs attention, it is on the quote, not a surprise on the day.

  3. 03

    Install day

    The outdoor unit goes on a solid base, pipes are run and covered, and the unit gets its own circuit. We clean up and test it with you in the room.

  4. 04

    Handover and paperwork

    We show you the remote and the filters. You get a Certificate of Compliance for the electrical work, an Electrical Safety Certificate when new work is connected, and the warranty details.

For landlords

The Healthy Homes heating standard

18°C

Rental homes must have fixed heating that can warm the main living room to at least 18°C. A correctly sized heat pump is the usual way to meet it.

  • Sized to the living room, not a rule of thumb
  • Install and electrical done together, with certificates
  • Servicing to keep it running between tenancies
